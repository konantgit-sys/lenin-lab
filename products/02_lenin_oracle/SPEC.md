# Lenin Oracle Bot — Спецификация
# Telegram: @lenin_oracle_bot
# Статус: 🟡 SPEC READY

## КОНЦЕПЦИЯ

«Спроси Ленина — получи реальную цитату».
Никаких LLM-галлюцинаций. Только реальные слова из 55 томов.

## АЛГОРИТМ

1. Пользователь: «Что Ленин думал о кооперации?»
2. Эмбеддинг вопроса (sentence-transformers)
3. FAISS.search(embedding, k=10)
4. Фильтр: distance < 0.7, уникальные тома
5. Сборка ответа:
   «В 1921 году (том 45) Ленин писал:
   "Кооперация — это тот путь..."
   А ранее, в 1899 (том 3):
   "Кооперативное движение..."»
6. Кнопки: «Ещё цитата» | «Другая позиция» | «Контекст»
