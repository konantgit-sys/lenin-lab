# Generative Art — Продукт #10
# Статус: ✅ LIVE
# URL: https://lenin-book.v2.site/products/10_generative_art/

## ОПИСАНИЕ
Генеративное искусство на основе данных корпуса Ленина. Частицы визуализируют 206 концептов из 8 кластеров в реальном времени.

## РЕЖИМЫ
- **Flow** — плавное течение, связи между частицами одного кластера
- **Burst** — частицы реагируют на движение мыши, разлетаются при приближении
- **Orbit** — орбитальное вращение вокруг центра
- **Drift** — случайный дрейф, броуновское движение

## ТЕХНИЧЕСКИЕ ДЕТАЛИ
- Canvas 2D, requestAnimationFrame
- Цветовая палитра: советский конструктивизм
- 300 частиц, адаптивно под размер экрана
- FPS-счётчик
- Загрузка реальных данных концептов через /api/concepts
- Оффлайн-режим с синтетическими данными

## ФАЙЛЫ
- `index.html` (9.3 KB) — полное приложение (HTML+CSS+JS)
- API: `/api/concepts` — данные концептов
