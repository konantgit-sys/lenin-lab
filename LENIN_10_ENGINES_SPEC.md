## ФАЗА 1: ХРОНОЛОГИЧЕСКАЯ РАЗМЕТКА

**Длительность:** 45 мин
**Зависимости:** нет (работает с существующей БД)

### Что делает
Размечает каждый параграф годом/периодом. Сейчас в БД есть volume_id и paragraph_index, но нет времени написания.

### Алгоритм
1. Загрузить маппинг том→год из метаданных ПСС (55 томов, 1893–1923)
2. Разметить все 169 067 параграфов: `ALTER TABLE paragraphs ADD COLUMN year INTEGER`
3. Добавить периодизацию: дореволюционный (1893–1916), революция (1917), советский (1918–1923)
4. Создать индекс по year

### API
```python
get_chronology_stats() -> {
    "year_range": "1893-1923",
    "paragraphs_with_year": 169067,
    "distribution": {1893: 1245, 1894: 2100, ...},
    "periods": {
        "pre_revolution": 98234,
        "revolution": 12450,
        "soviet": 58383
    }
}
```

### Тесты
- Все 169 067 параграфов имеют year ≠ NULL
- year в диапазоне 1893–1923
- Распределение совпадает с ожидаемым (по номерам томов)
- Периодизация корректна

### Визуализация
Столбчатая диаграмма: годы по X, количество параграфов по Y. Три цвета по периодам.

### Критерий готовности
- Колонка year в БД
- `engine_01_chronology.py` — 2 функции (разметка + статистика)
- `test_01_chronology.py` — 4 теста, все зелёные
- Эндпоинт `/engines/chronology` на лендинге

## ФАЗА 2: КОНЦЕПТУАЛЬНЫЙ ГРАФ

**Длительность:** 90 мин
**Зависимости:** Фаза 1 (год для фильтрации)

### Что делает
Извлекает 200 ключевых ленинских концептов, строит граф совместной встречаемости, находит 8-12 кластеров (community detection).

### Алгоритм
1. Определить 200 концептов (диктатура пролетариата, империализм, партия, государство, революция, НЭП, национальный вопрос, etc.)
2. Для каждого концепта — набор ключевых слов (синонимы + словоформы)
3. Просканировать все 169K параграфов: если в одном параграфе встречаются концепты A и B → ребро с весом +1
4. Louvain community detection → 8-12 кластеров
5. Для каждого кластера — название (автоматическое, по топ-3 концептам)

### API
```python
get_concept_graph() -> {
    "nodes": 200,
    "edges": 4523,
    "clusters": 10,
    "cluster_names": ["Экономика", "Партия", ...],
    "top_edges": [(диктатура, государство, 1234), ...]
}

get_concept_evolution(concept: str) -> {
    "concept": "диктатура пролетариата",
    "by_year": {1905: 12, 1917: 89, 1921: 34}
}
```

### Тесты
- Ровно 200 узлов в графе
- Нет изолированных концептов (degree > 0)
- 8–12 кластеров
- Каждый кластер имеет осмысленное имя
- `get_concept_evolution` возвращает данные по годам

### Визуализация
Force-directed граф (D3.js): 200 узлов, рёбра по весу, кластеры цветами.

### Критерий готовности
- `engine_02_concepts.py` — поиск концептов + граф + кластеризация
- `test_02_concepts.py` — 5 тестов
- Граф загружается в JSON для D3.js на лендинге
- Эндпоинт `/engines/concepts`

## ФАЗА 3: ДИАЛЕКТИЧЕСКИЙ ПАРСЕР

**Длительность:** 60 мин
**Зависимости:** нет

### Что делает
Извлекает диалектические тройки: тезис → антитезис → синтез. Маркеры: «но», «однако», «следовательно», «на самом деле», «в действительности», «напротив».

### Алгоритм
1. Для каждого параграфа искать маркеры противоречия
2. Если маркер найден: текст до = тезис, маркер + текст после до точки = антитезис
3. Агрегировать: два соседних параграфа с антитезисами → синтез
4. Классифицировать тип диалектики: полемическая (против оппонента), теоретическая (развитие мысли), практическая (анализ ситуации)

### API
```python
get_dialectic_triples(limit=100) -> [
    {
        "thesis": "...",
        "antithesis": "...",
        "synthesis": "...",  # может быть null
        "marker": "но",
        "type": "polemical",
        "year": 1917,
        "volume": 34
    }
]

get_dialectic_stats() -> {
    "total_triples": 15234,
    "by_type": {"polemical": 8234, "theoretical": 4100, "practical": 2900},
    "top_markers": {"но": 6234, "однако": 2100, "на самом деле": 890}
}
```

### Тесты
- Не менее 10K диалектических троек найдено
- Каждая тройка имеет thesis и antithesis (синтез опционален)
- Маркер присутствует в antithesis
- Тип классификации корректен для ≥80% (ручная проверка 100 случайных)

### Визуализация
Sankey-диаграмма: поток от тезиса → антитезис → синтез, цвет по типу.

### Критерий готовности
- `engine_03_dialectic.py` — парсер + классификатор
- `test_03_dialectic.py` — 4 теста
- Эндпоинт `/engines/dialectic`

## ФАЗА 4: КАРТА ОППОНЕНТОВ

**Длительность:** 60 мин
**Зависимости:** нет (но использует год из Фазы 1 если доступен)

### Что делает
Извлекает все полемические фрагменты, идентифицирует оппонентов (Каутский, Мартов, Троцкий, Плеханов, Бернштейн, меньшевики, эсеры, etc.), строит «поле боя идей».

### Алгоритм
1. Список оппонентов: имена + варианты (Карл Каутский, Каутский, Kautsky, «ренегат»)
2. Поиск FTS5 по всем упоминаниям
3. Для каждого упоминания — контекст (±2 параграфа), тон (позитивный/негативный/нейтральный)
4. Группировка: оппонент × тема × год → матрица противостояний
5. Тема определяется через концепты из Фазы 2

### API
```python
get_opponent_map() -> {
    "opponents": [
        {"name": "Каутский", "mentions": 2341, "tone": "negative", "peak_year": 1918},
        ...
    ],
    "battles": [
        {"opponent": "Каутский", "topic": "диктатура пролетариата", "year": 1918, "intensity": "high"},
        ...
    ]
}
```

### Тесты
- Не менее 15 оппонентов идентифицировано
- Каутский и Мартов в топ-5 по упоминаниям
- Тон определён для ≥90% упоминаний
- Темы сопоставлены для ≥70% упоминаний

### Визуализация
Bubble chart: размер = упоминания, цвет = тон, позиция X = время, Y = оппонент.

### Критерий готовности
- `engine_04_opponents.py` — поиск + классификация + маппинг
- `test_04_opponents.py` — 4 теста
- Эндпоинт `/engines/opponents`

## ФАЗА 5: МАШИНА ВРЕМЕНИ + ХРОНО-СЕМАНТИЧЕСКИЙ ПОИСК

**Длительность:** 90 мин
**Зависимости:** Фаза 1 (год), Фаза 2 (концепты)

### Что делает
API: дата на вход → что Ленин писал, какие концепты активны. Плюс поиск: концепт + год/период → релевантные параграфы.

### Алгоритм
1. Машина времени: date → SQL `WHERE year = ?` → параграфы за этот период
2. Контекст: какие концепты активны в этот период (из Фазы 2)
3. Против кого направлено (из Фазы 4, если Фаза 4 готова)
4. Поиск: FTS5 по концепту + фильтр по году → параграфы, сортировка по релевантности
5. Поддержка диапазонов: 1893-1900, 1901-1904, 1905-1907, 1914-1916, 1917, 1918-1921, 1922-1923

### API
```python
get_time_machine(year: int, month: int = None) -> {
    "period": "1917-10",
    "paragraphs": [...],
    "active_concepts": ["революция", "государство", "партия"],
    "opponents": ["Каутский", "меньшевики"],
    "total_chars": 45230
}

search_chrono(query: str, year_from: int, year_to: int) -> {
    "results": [{"text": "...", "year": 1917, "volume": 34, "rank": 0.95}],
    "total": 234
}
```

### Тесты
- `get_time_machine(1917, 10)` возвращает параграфы октября 1917
- `get_time_machine(1917)` возвращает непустой результат
- `search_chrono("банки", 1914, 1918)` находит релевантные параграфы
- Диапазон 1893–1923 возвращает все результаты

### Визуализация
Хронологическая шкала (Timeline.js): 30 лет, ключевые события, активные концепты, полемики.

### Критерий готовности
- `engine_05_timemachine.py` — time_machine + chrono_search
- `test_05_timemachine.py` — 4 теста
- Эндпоинты `/engines/timemachine?year=1917` и `/engines/search?q=...&from=...&to=...`

## ФАЗА 6: РИТОРИЧЕСКИЙ ОТПЕЧАТОК

**Длительность:** 45 мин
**Зависимости:** Фаза 1 (год для хронологии)

### Что делает
Стилометрия Ленина: эмоциональная дуга, риторические режимы, стилистические маркеры.

### Алгоритм
1. Для каждого параграфа посчитать:
   - Долю восклицательных знаков (!)
   - Долю вопросительных знаков (?)
   - Долю ЗАГЛАВНЫХ слов (Caps Lock)
   - Долю кавычек (прямая речь/ирония)
   - Долю саркастических маркеров («так называемый», «якобы», «пресловутый»)
2. Агрегировать по годам → эмоциональная дуга
3. Классифицировать параграфы: теоретический, полемический, организационный, саркастический

### API
```python
get_rhetoric_profile() -> {
    "emotional_arc": [
        {"year": 1905, "exclamation_pct": 2.3, "caps_pct": 1.2, "sarcasm_pct": 0.8},
        ...
    ],
    "peak_emotion_year": 1917,
    "calmest_year": 1894,
    "modes": {
        "theoretical": 45230,
        "polemical": 38120,
        "organizational": 28910,
        "sarcastic": 12450
    }
}
```

### Тесты
- Эмоциональная дуга содержит 30 точек (по году)
- Пик эмоций = 1917 (революционный год)
- Режимы в сумме = 169 067 параграфов (±1%)
- Саркастические маркеры корректно срабатывают (ручная проверка 20)

### Визуализация
Линейный график: 4 линии (!, ?, CAPS, сарказм) по годам. Аннотации ключевых событий.

### Критерий готовности
- `engine_06_rhetoric.py` — стилометрия + классификатор
- `test_06_rhetoric.py` — 4 теста
- Эндпоинт `/engines/rhetoric`

**Длительность:** 120 мин

   - Найти 10 самых репрезентативных параграфов (FTS5 + FAISS)

```python
get_canonical_positions(topic: str = None) -> {
```

## ФАЗА 8: ТЕМАТИЧЕСКИЕ СКВОЗНЫЕ НИТИ

**Длительность:** 60 мин
**Зависимости:** Фаза 1 (год), Фаза 2 (концепты)

Биография каждой темы внутри Ленина: где возникает, где достигает пика, где исчезает. Как биография человека, но биография идеи.

### Алгоритм
1. Для каждого из 50 концептов (из Фазы 7):
   - Частота упоминаний по годам
   - Первое появление (год, том)
   - Пик (год, том)
   - Последнее появление
   - Контекст первого появления
   - Связанные концепты в момент пика
2. Классификация темы: сквозная (весь период), периодическая (всплески), терминальная (исчезает)

### API
```python
get_topic_biography(topic: str) -> {

    "first_appearance": {"year": 1921, "volume": 43},
    "peak": {"year": 1922, "frequency": 89},

```

### Тесты
- 50 биографий (по одной на тему)
- Каждая имеет first_appearance, peak, last_appearance
- peak.year ≥ first_appearance.year
- Тип классификации корректен (ручная проверка 10)

### Визуализация
Горизонтальная полоса: 30 лет, линии тем, яркость = частота. Фильтр: сквозные/периодические/терминальные.

## ФАЗА 9: КВАНТОВЫЕ ЦИТАТЫ

1. Извлечь 12-15K цитат из параграфов (по кавычкам + семантическая фильтрация)

   - Риторический режим (из Фазы 6)
   - Диалектический тип (из Фазы 3, если применимо)
   - Тема (из Фазы 7)
3. Создать FAISS-индекс по цитатам (лёгкий, 35-40 MB)
4. Создать SQLite-таблицу quotes с колонками для всех измерений

### API
```python
search_quotes(

            "text": "«...»",

            "mode": "polemical",

get_random_quote(topic: str = None) -> {...}
```

### Тесты
- 12-15K цитат в БД
- Каждая имеет год, концепт, тему
- `search_quotes(concept="государство", year_from=1917)` возвращает результаты
- `search_quotes(opponent="Каутский", mode="sarcastic")` возвращает саркастичные цитаты
- FAISS-индекс < 50 MB

### Визуализация
Панель фильтров (выпадающие списки: концепт, год, оппонент, режим) → сетка цитат-карточек.

### Критерий готовности
