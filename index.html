🔑 Аутентификация

Все эндпоинты /api/v1/* требуют заголовок X-API-Key.
Получить бесплатный ключ (100 запросов/день):
curl -X POST "https://lenin-book.v2.site/api/v1/register?tier=free"

Тарифы: free=100, basic=1 000, pro=10 000 запросов/сутки
Ошибки: Все возвращают HTTP 200 + {"error":true,"code":401,"detail":"..."}

🛡 Безопасность

• API-ключ — middleware на всех v1 (401 missing, 403 invalid)
• Rate limiting (API-key) — 100/1 000/10 000/день (free/basic/pro)
• Rate limiting (IP) — 10/день на register, 500/день на legacy /api/*
• Ротация ключей — POST /api/v1/rotate-key, старый инвалидируется
• CORS — только lenin-book.v2.site и localhost
• FTS5 injection — спецсимволы и операторы вырезаются
• Скрытие ошибок — «internal error», детали в лог сервера
• Валидация — год 1893–1922, лимит 1–100, query не пустой

О проекте «Ленин-Бук»

Методология, архитектура и история создания

Зачем это нужно

55 томов Ленина — это 169 067 параграфов, 48 миллионов символов, 30 лет текста (1893–1922). Ни один человек не способен удержать этот объём в голове. Традиционные методы — чтение, конспектирование, индексация — не дают полноты картины и межтекстовых связей.

Ленин-Бук решает эту проблему: машинный анализ всего корпуса, извлечение структуры, связей, противоречий и закономерностей. Это не замена чтению — это инструмент, который делает чтение осмысленным и навигацию мгновенной.

Прозрачность методов

Исследовательская платформа обязана быть честной о том, как получены её данные. Ниже — разбор каждого компонента.

✓ ВОСПРОИЗВОДИМО
Цитаты (aphorism_score)
Rule-based скоринг: 8 паттернов (длина, модальность, универсалии, ключевые концепты). extract_quotes.py открыт, методика документирована. Любой может перезапустить на своём корпусе.
✓ ВОСПРОИЗВОДИМО
Оппоненты + споры
Парсинг корпуса: поиск имён (Бернштейн, Каутский, Плеханов…) + маркеры обвинения (оппортунизм, предательство, ревизионизм). Все 21 dispute с реальными paragraph_id и текстовыми превью.
✓ ВОСПРОИЗВОДИМО
Фантомные оппоненты
149 instances — не магия. Маркерный поиск: «нам говорят», «нам скажут», «нам возражают», «кричат», «уверяют». Каждый фантом привязан к конкретному году, тому, параграфу и контексту Ленина.
✓ БЕЗ LLM
Цифровой двойник
FAISS + FTS5 гибридный поиск. Ноль генерации — только retrieval реальных цитат из корпуса. Ответ собирается из найденных параграфов. Никаких галлюцинаций.
✓ ПРОЗРАЧНО (требует валидации)
Граф концептов (206 узлов, 12 735 рёбер)
Метод: Co-occurrence на 169K параграфах. Концепты: ручной словарь из 200+ терминов с падежными формами (16 категорий). Рёбра: совместное вхождение в один параграф. Кластеры: Louvain community detection, seed=42. Код: engine_02_concepts.py — полностью читаем.
Слабость: ручная валидация не проводилась, precision/recall не замерялись.
⚠ ПРЕДВЫЧИСЛЕНО
Томография (UMAP 2D)
Координаты предвычислены внешним пайплайном из 93 711 FAISS-векторов (384d → 2d). Проекция статична. Параметры UMAP (n_neighbors, min_dist, metric) и seed — не в коде. Этот компонент — единственный чёрный ящик.

Честный итог аудита: 4 компонента полностью воспроизводимы (цитаты — rule-based, оппоненты — парсинг, фантомы — маркерный поиск, двойник — retrieval). Граф концептов — метод прозрачен (co-occurrence + Louvain), но без ручной валидации. Томография — единственный компонент с внешним пайплайном. Свяжитесь с нами — предоставим сырые данные для независимой проверки.
