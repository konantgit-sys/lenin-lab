Lenin Search — Obsidian Plugin

Поиск по 55 томам Ленина прямо из твоих заметок
⚡ Использует Lenin API v1 (25 эндпоинтов, FAISS+FTS5, 169K параграфов)

Установка

  1. Скачай архив плагина
  2. В Obsidian: Настройки → Community Plugins → включи Restricted Mode OFF
  3. Распакуй архив в .obsidian/plugins/lenin-search/ (в папке твоего vault)
  4. Включи плагин: Настройки → Community Plugins → Lenin Search → ON
⬇️ Скачать lenin-search.zip

Команды

Ctrl+P → «Поиск по Ленину»

Выдели текст (или введи запрос) → поиск по 169K параграфов → вставляет цитату с годом и томом.

Ctrl+P → «Инфо о концепте»

Выдели слово (например «империализм») → показывает частоту, пик, кластер, связи с другими концептами.

Ctrl+P → «Случайная цитата Ленина»

Вставляет случайную цитату с атрибуцией в текущую позицию курсора.

Горячие клавиши (настрой)

Ты можешь назначить свои сочетания в Настройки → Hotkeys:

Ctrl+Shift+L → случайная цитата
Ctrl+Shift+K → поиск по Ленину
Ctrl+Shift+I → инфо о концепте
